## 背景

Obico 是一款给 3D 打印机做"远程监控 + AI 失败检测"的开源平台。客户希望把原本的网页端体验做成原生移动 App，以便在外出/睡觉时也能盯着打印进度、出问题立即收到推送。

## 我的工作

- Flutter 双端 App（iOS + Android）
- WebRTC 实时摄像头流接入（多机型适配）
- 打印任务面板：进度、温度、Z 高度、暂停/取消
- 推送通知：AI 检测到打印失败（spaghetti / 喷头堵塞）实时通知
- 与现有 Django 后端的 REST API 对接
