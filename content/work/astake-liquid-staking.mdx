## 背景

Astar 网络的官方 dApp Staking 把 ASTR 锁定在 dApp 上获取奖励，但锁定期间无法用于其他 DeFi 操作。Astake 让用户把 ASTR 换成 nASTR（一种带息的衍生代币），既能获得 staking 收益，又能在 DEX 里继续流通。

## 我的工作

- 主导从需求 → 合约对接 → 前端实现 → 上线的全流程
- Vue 3 Composition API + Vite + PrimeVue 构建管理界面
- 用 `@reown/appkit` (前 WalletConnect Web3Modal) 多链钱包集成
- Wagmi/Vue + Viem v2 替代 ethers v5（性能与类型双提升）
- 上线后的运维 + 与 Astar 团队协作的 dApp Staking v3 升级
