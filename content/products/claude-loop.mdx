## 是什么

Claude Code 默认是单次会话——给你回应一次就停了。Claude Loop 是个轻量包装器，让你给一个 prompt 设定"每 N 秒重新触发一次"或"按 cron 表达式触发"。

## 为什么

我自己写代码时常需要让 AI 周期性做事——"每 5 分钟看一下部署日志"、"每天 9 点把昨天的进度整理成日报"。把这些自动化下来后，AI 真正变成了一个能"自我推进"的协作者。

## 当前状态

`beta` —— 已经在我自己的工作流里跑了 3 个月，最近 1 个月内会开放 Claude Code 用户社区试用。
